AVANT DE MONTER À BORD

Ça se passe comment ?

C’est gratuit ? Et officiel ?

Flightdeck est un projet communautaire pour Real Flight Simulator. Il n’est pas affilié à Rortos. Aucun abonnement ni achat n’est nécessaire dans l’application.

Est-ce que je peux jouer sans Internet ?

Sur Windows et Android, les messages, la recherche de vols et le calcul carburant fonctionnent hors ligne. Les couches satellite, vents réels et vérifications de mises à jour sont facultatives et utilisent Internet si vous les activez.

Le site et les applications sont-ils identiques ?

Le site permet d’essayer les messages et le carburant dans un prototype limité. Pour la base de vols locale, la carte et les outils complets, installez l’application Windows ou Android. L’iPhone n’a pas encore d’application équivalente.

Comment conserver mon vol entre PC et téléphone ?

Exportez la sauvegarde JSON dans l’application, transmettez le fichier à l’autre appareil et importez-le. Un aperçu permet de choisir Fusionner ou Remplacer. Il n’y a pas encore de synchronisation automatique.

Une mise à jour peut-elle effacer mes données ?

Exportez une sauvegarde avant de changer de version. Sur Android, installez par-dessus l’application existante avec la même signature. Une désinstallation efface les données privées. Le guide détaille les cas où les APK de test ont une signature différente.

Je ne trouve pas le téléchargement ou mon vol.

Pour télécharger, connectez-vous à GitHub et ouvrez l’artefact du build vert. Pour un vol absent, élargissez les filtres ou essayez le catalogue des routes observées. La base ne couvre pas tous les vols ; aucun résultat fictif n’est ajouté.
