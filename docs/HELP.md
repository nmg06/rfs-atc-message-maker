# Comprendre Flightdeck

Dans l’application, **Comprendre cet écran** explique la rubrique ouverte.
Le tutoriel présente quatre étapes courtes, avec **Précédent**, **Suivant** et
**Ouvrir cette rubrique / Essayer**. Vous pouvez le passer : vos informations
restent conservées.

Pour le retrouver : **Aide et retours** sur Windows, **Paramètres → Aide à bord**
sur Android, ou **Aide** dans le prototype web. Les **30 questions fréquentes**
sont consultables et recherchables hors ligne. Elles suivent votre langue.
Le prototype web précise quelles explications concernent les applications.

## Copier à votre manière

**Vérifier avant copie** est activé au départ. Dans ce mode, les champs requis,
la longueur et les emojis sont contrôlés. Appuyez sur un avertissement pour
ouvrir la rubrique et retrouver le champ à remplir. Un avertissement de longueur
ou d’emojis vous ramène au texte à raccourcir.

Désactivez cette option pour copier votre message même incomplet. Les alertes
restent visibles, et le choix est conservé après fermeture. L’application ne
remplit pas les champs manquants à votre place et n’envoie aucun message.
Le format Discord choisi reste appliqué. Un aperçu vide ne peut pas être copié.

## Deux durées différentes

La **durée totale** du vol sert à préparer le carburant. L’**ETE dans
ARRIVAL BOARD** décrit le temps restant : **5 min signifie une arrivée prévue
dans environ cinq minutes**.

## Si quelque chose semble bloqué

Dans une liste d’avions, utilisez la recherche, la molette ou le défilement
tactile. Sur téléphone, la croix des paramètres revient à l’écran précédent,
et Retour ferme d’abord le sélecteur ou l’aide ouverts.

Changer de langue traduit les commandes, listes et explications ; cela garde
les informations que vous avez saisies. Les fenêtres de fichiers Android
peuvent suivre la langue du système. Consultez les avertissements du Finder
avant d’utiliser un vol historique. Les portes absentes ne sont pas devinées.

Le site reste un **prototype**, avec messages partiels, calcul Fuel issu des
références PC et stockage navigateur. Il n’embarque pas le Finder SQLite Android.
Pour l’expérience complète actuellement disponible, installez Windows ou Android :
[guide d’installation](INSTALLATION.md).
