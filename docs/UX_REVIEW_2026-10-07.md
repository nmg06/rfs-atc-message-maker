# Revue produit et refonte — 7 octobre 2026

Branche : `feat/flightdeck-user-experience`. Public : joueurs de Real Flight
Simulator, novices GitHub comme pilotes réguliers, avec ou sans ATC.

## Constats avant modification

- La racine du site ouvre une copie ancienne du formulaire mobile, sous l’ancien
  nom. Aucun parcours clair pour choisir Windows/Android ou comprendre iPhone.
- Le prototype et l’application complète ne sont pas clairement distingués à
  l’entrée. Un visiteur peut croire que Flight Finder existe dans le navigateur.
- Le formulaire commence par les designs/emojis avant le trajet. Le premier
  écran est rempli de contrôles plutôt que d’une action facile à choisir.
- Android propose sept minuscules onglets ; la même page centrée gaspille
  l’espace PC. Les résultats ont quatre actions concurrentes par ligne.
- Recherche : longue liste de critères, état vide peu utile, pas de comparaison.
- Plusieurs labels/aperçus n’ont pas de nom accessible ; le chargement initial
  affiche un texte brut si le moteur échoue, sans bouton de reprise.

Audit par lecture des moteurs partagés, interface, stockage, scripts de build,
tests ; navigation du prototype dans le navigateur. Socle avant modification :
173 tests Windows, 32 tests Android et neuf parcours navigateur réussis.

## Choix

1. Une entrée publique éditoriale, légère, bilingue, avec installation guidée,
   état réel des plateformes, conservation du brouillon et contraste/focus.
2. Un espace de préparation responsive : trajet d’abord, actions contextuelles,
   navigation adaptée, filtres principaux courts et détails progressifs.
3. Comparer des résultats réels, sans fabriquer des durées, avions ou horaires.
4. Respect des données et de la logique Python ; aucun serveur, CDN, compte ou
   suivi ajouté. La version Windows PySide6 reste compatible.

Les artefacts de test restent temporaires. Cette branche ne publie aucune release
ni nouvelle version du site en production automatiquement. La vérification visuelle
mobile utilise un viewport Android ; elle ne remplace pas un téléphone physique.
